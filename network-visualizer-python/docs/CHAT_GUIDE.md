# Network Visualizer Chat Guide

Welcome to the Network Visualizer assistant! This guide will help you effectively communicate with the assistant to analyze and visualize your network data.

## Getting Started

Start your conversation with any of these prompts:

- "Help me visualize a network from a CSV file"
- "Analyze my network's community structure"
- "Show me the most central nodes in my network"
- "Compare different layout algorithms for my network"
- "Generate a report of network metrics"

## Supported File Formats

You can work with these network file formats:
- CSV/TSV edge lists
- GraphML (.graphml)
- GML (.gml)
- JSON graph format
- Edge lists (.txt)

## Common Tasks

### Loading Data
- "Load my network from [filename]"
- "Import data from [URL]"
- "Connect to Neo4j database at [connection_string]"

### Visualization
- "Show the network with a force-directed layout"
- "Color nodes by degree"
- "Size nodes by betweenness centrality"
- "Apply a circular layout"
- "Animate network evolution"

### Analysis
- "Calculate degree distribution"
- "Find communities in the network"
- "Show the shortest path between node A and B"
- "Identify key influencers"
- "Calculate network density"

### Exporting Results
- "Export the visualization as PNG"
- "Save the network as GraphML"
- "Generate a PDF report"

## Tips for Better Results

1. Be specific about your analysis goals
2. Mention the type of network (social, biological, infrastructure, etc.)
3. Specify if you're interested in particular nodes or communities
4. Let the assistant know if you have any visualization preferences
5. Ask for help interpreting any metrics or visualizations

## Example Workflow

1. "Load the social_network.csv file"
2. "Show me the network with nodes colored by community"
3. "What are the top 5 most central nodes?"
4. "Export this visualization as a high-res PNG"

## Need Help?

Type "help" at any time to see available commands and features.
